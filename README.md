# Relios Export

TikTok ve YouTube icin video disa aktarma programi (FFmpeg + FDK AAC).

- `ffmpeg-build/` : FFmpeg'in (libfdk_aac dahil) Windows 64-bit derlemesi.
  GitHub Actions'ta en son kararli surumlerle derlenir.
- Program kodu: hazirlaniyor.

Not: libfdk_aac iceren derleme yeniden dagitilamaz; bu depo ozel kalmalidir.
